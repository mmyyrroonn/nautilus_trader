## Added source-retention contract

Tests capture the actual active native query token and the verified metadata reader generation/epoch at query start. Debt must have kind `unknown_sources`, retain the captured token/generation/epoch/account/address/policy, and expose a native received-sequence identity. Each original source request JSON and raw body must match an actually recorded normal peer request/response. Its native transport `received_ms` must be within the measured query interval. Peer server times establish only a lower bound; they do not replace native client receive timestamps.

The original assertions for source races, owner dispatch expiry, identical private frame after staging, normal disconnect, closed runner channel, and retired epoch-zero factory now require original source preservation alongside no Ready and no financial effects. The stopped callback cannot replace existing debt. A new normal epoch-zero factory cannot adopt the old factory's retained evidence.

The finite completion helper waits until the actual query-in-flight diagnostic is false before treating a negative diagnostic as settled. An earlier private invalidation cannot masquerade as completed raw preservation.

Six new normal peer cases combine:

- A real identical private frame, changed funds frame, or reader close.
- A later malformed actual `userFills` body or the unchanged three-second query deadline.

Each case first waits for the normal `userFills` request. This proves the preceding actual frontendOpenOrders body was received and parsed. The subsequent real reader change cannot discard that received original body. A malformed body must remain original evidence; a timed-out body must remain explicitly unavailable with its original request and null receive time. Neither outcome can become a financial grant, gain a native projection, or be reassigned to a later query. A repeated ordinary QueryAccount is rejected without additional HTTP, preserves exact debt, and makes no signed action. Normal stop/drop releases the Windows journal lock, after which the actual persisted final record must contain debt exactly equal to the observed native snapshot.

These tests preserve the existing native byte/deadline/event/action limits. The oversized-source test continues to distinguish finite missing-raw debt from claims that an over-cap body was durably preserved. Original complete raw bodies in the ordinary race cases are small and remain within the existing journal bound.
