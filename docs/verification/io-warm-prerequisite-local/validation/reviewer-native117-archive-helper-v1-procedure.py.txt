import datetime
import hashlib
import json
import re
from pathlib import Path

root = Path('E:/persarb/_tmp/entropy117-validation')
helper = root / 'archive_native117.py'
expected = '37c5c76f1d0d3707b113eb7d4f2c0d4e5fcfbcee4aae2190f3d7fcee527399d6'
label = 'reviewer-native117-archive-helper-v1'
sha = lambda p: hashlib.sha256(p.read_bytes()).hexdigest()
now = lambda: datetime.datetime.now(datetime.timezone.utc).isoformat()
started = now()
original = helper.read_bytes()
assert hashlib.sha256(original).hexdigest() == expected
copy = root / (label + '-source.py.txt')
assert not copy.exists()
copy.write_bytes(original)
names = ['native117-full-hyperliquid-regression-v6.json', 'native117-full-hyperliquid-regression-v6.log',
         'native117-implementation-commit.json', 'native117-verified-binaries-v6.json',
         'native117-formatted-v6.json', 'native117-after-full-regression-v6.json',
         'native117-full-inputs-unchanged-v6.json', 'native117-full-source-comparison-v6.json']
inputs = [helper, copy, Path(__file__)] + [root / name for name in names]
before = [{'path': str(p), 'sha256': sha(p)} for p in inputs]
load = lambda name: json.loads((root / name).read_text(encoding='utf-8'))
command = load(names[0])
groups = [list(map(int, row)) for row in re.findall(r'test result: ok\. (\d+) passed; (\d+) failed; (\d+) ignored; (\d+) measured; (\d+) filtered out', (root / names[1]).read_text(encoding='utf-8'))]
totals = [sum(row[i] for row in groups) for i in range(5)]
assert totals == [1424, 0, 18, 0, 0] and command['exit_code'] == 0
implementation = load(names[2])
binary = load(names[3])
pre = load(names[4])
post = load(names[5])
assert implementation['reviewed_manifest_sha256'] == binary['source_manifest']['sha256'] == sha(root / names[4])
assert binary['actual_cargo_command']['sha256'] == sha(root / names[0])
assert binary['actual_cargo_log']['sha256'] == sha(root / names[1])
for relative, digest in implementation['files'].items():
    for source in (pre, post):
        row = next(x for x in source['native']['files'] if Path(x['path']).relative_to(Path(source['native']['root'])).as_posix() == relative)
        assert row['sha256'] == digest
after = [{'path': str(p), 'sha256': sha(p)} for p in inputs]
assert before == after
result = {'started_utc': started, 'finished_utc': now(), 'helper_sha256': expected,
          'reviewer_executed_tests': 0, 'helper_executed': False,
          'archive_created': False, 'git_invoked_by_reviewer': False,
          'before': before, 'after': after, 'unchanged': True,
          'root_regression_log_observed_totals': totals,
          'root_regression_command_utc': {'started': command['started_utc'], 'finished': command['finished_utc']},
          'existing_external_chain_matches': True,
          'verdict': 'One source-binding preflight blocker in helper v1; external actual receipts already supply the missing chain.',
          'blocker': {'lines': [84, 118, 132], 'detail': 'Regression cwd/argv/counts and current Git blobs are separately verified; the selected regression pre/post source manifest is not checked against implementation blobs. tested_file_sha256 is only current source in this helper.',
                      'minimal_fix': 'Bind selected regression command/log hashes through native117-verified-binaries-v6.json, reviewed manifest hash from implementation receipt, and original before/after source capture five-file hashes to the implementation blobs; verify source capture times encompass the selected run.'},
          'limits': ['Static review only; no helper execution, archive or scenario run.', 'No reviewer Git invocation; exact Git-object logic assessed statically.', 'Future wheel/scenario existence and identities were not certified.', 'Observed existing root regression totals are not reviewer test counts.']}
output = root / (label + '.json')
assert not output.exists()
output.write_text(json.dumps(result, indent=2) + '\n', encoding='utf-8')
md = f'''# Native117 archival helper v1 independent review

Reviewed frozen helper SHA256 `{expected}` (19,631 bytes), preserved as `{copy.name}`. Read-only procedure UTC: {started} through {result['finished_utc']}. **0 reviewer tests; helper not executed; no archive created; no Git/native/build/install operation.**

## Finding: regression-to-implementation source chain missing

Helper v1 needs one preflight correction before it can independently assert tested-source binding. `verify_regression` (line 84) checks exact unfiltered Cargo argv/cwd, completion and 1424/0/18 totals. `verify_implementation` (line 118) separately verifies exact commit/base/HEAD, five changed paths, original Git blob bytes and current files. At line 132, `tested_file_sha256` is only the current file hash. No check binds the selected actual regression's original before/after sources to those blobs. A prior run in the same checkout with matching totals could pass that gate despite another tested revision.

This is a helper gap, not a finding that the actual final regression failed or has no provenance. The existing actual `native117-verified-binaries-v6.json` binds the selected command/log hashes to `native117-formatted-v6.json`; the implementation receipt already carries that reviewed-manifest hash. Original `native117-after-full-regression-v6.json` and the comparison receipt are also available. This review independently compared those existing JSON/hash chains and the five source hashes: they agree. A minimal helper fix can require that chain and compare original capture timestamps around the selected run, before archive creation. No new evidence or reconstructed execution is needed.

Disposition: **pending the source-chain gate**, otherwise no new material static blocker found in the requested scope. Future wheel/installed bytes and scenario outcomes remain unaccepted here. The companion JSON retains exact original helper and observed evidence hashes, all unchanged across the procedure. No author file was modified.
'''
output = root / (label + '.md')
assert not output.exists()
output.write_text(md, encoding='utf-8')
